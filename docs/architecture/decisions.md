# Owner decisions

Decisions the owner made about OnePedigree, newest first, each with its date. Most were passed on to this repo by another session and are marked "relayed"; quotes are the owner's choice as he picked it.

| Date | Decision |
| --- | --- |
| 2026-11-14 | **EXTANT APE owns OnePedigree:** the repo moves to `ExtantApe/OnePedigree` and the packages publish under `@extantape`, from 0.1.0-alpha.22. The old package names get deprecated with a pointer to the new ones. The owner approved the move. Relayed. |
| 2026-11-10 | **The studbook package name:** `onepedigree-studbook`. The owner chose "Yes, that name (Recommended)" when asked, before its first publish. Relayed. |
| 2026-11-10 | **The studbook gets a Mac app counterpart:** "Oh! I forgot. The Studbook needs a Mac app counterpart" (about 1:15 PM MST). Scope as it was relayed: the same two views (the project view and the formal studbook view), the same data model and the same exports (PDF, CSV, JSON, PMx), on local files with no server, planned with Tier A/B after tour v3. Plan: [studbook-mac.md](studbook-mac.md). Relayed. |
| 2026-11-10 | **Tour first, then the studbook:** "Let's do the tour before the Studbook addition so we don't have to wait, but we should mention the studbook features we've decided on and put it as in progress at time of doc compilation." Relayed. |
| 2026-11-10 | **Audit old values for a studbook record's own fields only** (dates, parents, status, location), never personal details. Built by the platform. Relayed. |
| 2026-11-10 | **Studbooks live in a OnePedigree extension:** "An onepedigree-studbook package: species-neutral numbering, kinship, founders and exports, which any group could use. [The platform] turns it on inside Assurance Projects." Relayed. |
| 2026-11-10 | **Each Assurance Project is a studbook:** "Simplest: one place, and it matches how projects already approve animal groups. A regional or international studbook could be added later if a program needs one across several projects." So the package keeps room for more than one studbook per site. Relayed. |
| 2026-11-10 | **Who sees mean kinship and gene diversity:** "The project coordinator sees everything; members see the numbers for their own animals, so they understand why a pairing is suggested." Relayed. |
| 2026-11-10 | **A lead's assignment of an animal to a keeper needs the keeper to accept, like a transfer.** This is built by the platform. Relayed. |
| 2026-11-09 | **Both IDs on every studbook animal:** the registry ID and the keeper's Animal ID are shown together, searchable by either, and in every export and report. Relayed. |

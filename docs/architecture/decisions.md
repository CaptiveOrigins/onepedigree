# Owner decisions

Decisions the owner made about OnePedigree, newest first, each with its date. Most reached this repo through the director session and are marked "relayed"; quotes are the owner's choice as he picked it.

| Date | Decision |
| --- | --- |
| 2026-11-10 | **Tour first, then the studbook:** "Let's do the tour before the Studbook addition so we don't have to wait, but we should mention the studbook features we've decided on and put it as in progress at time of doc compilation." Relayed. |
| 2026-11-10 | **Audit old values for a studbook record's own fields only** (dates, parents, status, location), never personal details. Built by the platform. Relayed. |
| 2026-11-10 | **Studbooks live in a OnePedigree extension:** "An onepedigree-studbook package: species-neutral numbering, kinship, founders and exports, which any group could use. Captive Origins turns it on inside Assurance Projects." Relayed. |
| 2026-11-10 | **Each Assurance Project is a studbook:** "Simplest: one place, and it matches how projects already approve animal groups. A regional or international studbook could be added later if a program needs one across several projects." So the package keeps room for more than one studbook per site. Relayed. |
| 2026-11-10 | **Who sees mean kinship and gene diversity:** "The project coordinator sees everything; members see the numbers for their own animals, so they understand why a pairing is suggested." Relayed. |
| 2026-11-10 | **A lead's assignment of an animal to a keeper needs the keeper to accept, like a transfer.** This is built by the platform. Relayed. |
| 2026-11-09 | **Both IDs on every studbook animal:** the Captive Origins ID and the keeper's Animal ID are shown together, searchable by either, and in every export and report. Relayed. |
